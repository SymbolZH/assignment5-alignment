4 组相对策略优化

测量了仅靠提示得到的表现后，下一步是通过训练改进它。具体来说，我们希望优化准确率，等价地，优化期望奖励：

Jθ=Ex∼ρEy∼πθ(y∣x)[r(y∣x)].(1)J_\theta=\mathbb E_{x\sim\rho}\mathbb E_{y\sim\pi_\theta(y\mid x)}[r(y\mid x)]. \tag{1}Jθ​=Ex∼ρ​Ey∼πθ​(y∣x)​[r(y∣x)].(1)

其中 ρ\rhoρ 是提示／问题 xxx 的任务分布，πθ\pi_\thetaπθ​ 是模型，yyy 是采样得到的回答，r(y∣x)r(y\mid x)r(y∣x) 表示 yyy 是否正确回答了 xxx，我们也将 rrr 称为奖励函数。

这与此前学习的预训练目标很不同：交叉熵损失 Ex∼D[−log⁡πθ(x)]\mathbb E_{x\sim\mathcal D}[-\log\pi_\theta(x)]Ex∼D​[−logπθ​(x)] 对数据集样本取期望，而准确率目标对模型自身生成的样本取期望。因此需要新的优化工具，尤其是 RL。其基本过程是从模型采样回答、评分、强化正确回答。RL 通常缓慢且困难，所以本作业的大量内容将探索如何使它更快、更稳定。

由于 RL 从模型自身采样，它的动态也受采样时提示的影响。语言模型研究中的一个令人振奋的发现是：使用思维链提示，对强基础模型执行 RL，可以大幅提高推理能力 [OpenAI 等，2024；DeepSeek-AI 等，2025]。因此，本作业除了核心 RL 算法，还将研究它与思维链提示等语言建模技术的相互作用。

4.1 推导同策略 GRPO

我们先研究 RL 的数学基础，逐步推导语言模型训练中常用的 GRPO 算法 [Z. Shao 等，2024]。这里的介绍紧密参考了两份更深入的优秀资料：OpenAI 的 Spinning Up in Deep RL [J. Achiam，2018]，以及 Nathan Lambert 的 Reinforcement Learning from Human Feedback (RLHF) Book [N. Lambert，2024]。

4.1.1 将语言模型视为策略

传统强化学习中，策略接收状态 sts_tst​ 并输出动作 ata_tat​。该动作带来奖励 rt=r(st,at)r_t=r(s_t,a_t)rt​=r(st​,at​)，并按照下一状态分布转移到 st+1∼next_state⁡(st,at)s_{t+1}\sim\operatorname{next\_state}(s_t,a_t)st+1​∼next_state(st​,at​)。RL 的目标是优化策略，使其获得高奖励。

参数为 θ\thetaθ 的因果语言模型 πθ\pi_\thetaπθ​，给定文本前缀 y<t=(y1,…,yt−1)y_{<t}=(y_1,\ldots,y_{t-1})y<t​=(y1​,…,yt−1​)，定义下一 token yty_tyt​ 的概率分布。因此，下一 token 对应动作，当前文本前缀对应状态。语言模型是一个类别分布上的随机策略：

at∼πθ(⋅∣st),πθ(at∣st)=[softmax⁡(fθ(st))]at.(2)a_t\sim\pi_\theta(\cdot\mid s_t),\qquad \pi_\theta(a_t\mid s_t)=[\operatorname{softmax}(f_\theta(s_t))]_{a_t}. \tag{2}at​∼πθ​(⋅∣st​),πθ​(at​∣st​)=[softmax(fθ​(st​))]at​​.(2)

使用策略梯度优化时需要两个基本操作：

  1. 从策略采样：从上述类别分布抽取动作 ata_tat​。
  2. 计算动作的对数似然：求 log⁡πθ(at∣st)\log\pi_\theta(a_t\mid s_t)logπθ​(at​∣st​)。

在 LLM 的 RL 中，sts_tst​ 通常是当前已生成的部分回答／解答，每个 ata_tat​ 是下一个 token；输出文本结束 token 时回合结束，例如 <|end_of_text|>，或 r1_zero 中的 </answer>。

4.1.2 轨迹

RL 从初始分布采样状态 s0∼ρs_0\sim\rhos0​∼ρ，再从策略采样动作，按照下一状态分布转移，并不断重复。状态和动作构成有限时域轨迹：

其中 TTT 表示轨迹长度：aTa_TaT​ 是文本结束 token，或者此时已经达到最大生成 token 预算。

在本作业中，初始状态就是包含数学题的提示 xxx，可能附有思维链指令或少样本示例。以此为前缀逐个采样 token，下一状态就是将生成 token 拼接到旧前缀，即 st+1=(st,at)s_{t+1}=(s_t,a_t)st+1​=(st​,at​)。轨迹也称为 episode 或 rollout，后文交替使用这些叫法。

4.1.4 策略梯度

现在可以介绍策略梯度算法。此后使用提示／回答的语言模型记号 (x,y)(x,y)(x,y)，不再使用状态／动作记号 (st,at)(s_t,a_t)(st​,at​)。

回顾期望奖励，即准确率目标：

Jθ=Ex∼ρEy∼πθ(y∣x)[r(y∣x)].(7)J_\theta=\mathbb E_{x\sim\rho}\mathbb E_{y\sim\pi_\theta(y\mid x)}[r(y\mid x)]. \tag{7}Jθ​=Ex∼ρ​Ey∼πθ​(y∣x)​[r(y∣x)].(7)

在推导之前，先注意这给出了一个直观算法：从数据集采样问题，从模型采样回答，计算样本上 r(y∣x)∇θlog⁡πθ(y∣x)r(y\mid x)\nabla_\theta\log\pi_\theta(y\mid x)r(y∣x)∇θ​logπθ​(y∣x) 的平均值，再做梯度更新。该表达式意味着提高高奖励回答的对数概率。重复此过程就得到基本 RL 训练循环。

推导用到对数导数技巧。回顾 (log⁡f(x))′=f′(x)/f(x)(\log f(x))'=f'(x)/f(x)(logf(x))′=f′(x)/f(x)，于是：

∇θπθ(y∣x)=πθ(y∣x)∇θlog⁡πθ(y∣x).(10)\nabla_\theta\pi_\theta(y\mid x)=\pi_\theta(y\mid x)\nabla_\theta\log\pi_\theta(y\mid x). \tag{10}∇θ​πθ​(y∣x)=πθ​(y∣x)∇θ​logπθ​(y∣x).(10)

直接应用可得：

∇θEy∼πθ(y∣x)[r(y∣x)]=∑y∇θπθ(y∣x)r(y∣x)(11)\nabla_\theta\mathbb E_{y\sim\pi_\theta(y\mid x)}[r(y\mid x)] =\sum_y\nabla_\theta\pi_\theta(y\mid x)r(y\mid x) \tag{11}∇θ​Ey∼πθ​(y∣x)​[r(y∣x)]=y∑​∇θ​πθ​(y∣x)r(y∣x)(11)

=Ey∼πθ(y∣x)[r(y∣x)∇θlog⁡πθ(y∣x)].(13)=\mathbb E_{y\sim\pi_\theta(y\mid x)}[r(y\mid x)\nabla_\theta\log\pi_\theta(y\mid x)]. \tag{13}=Ey∼πθ​(y∣x)​[r(y∣x)∇θ​logπθ​(y∣x)].(13)

这里省略了提示上的期望 Ex∼ρ\mathbb E_{x\sim\rho}Ex∼ρ​，因为它可以与 ∇θ\nabla_\theta∇θ​ 交换顺序。

给定独立同分布采样的提示 x(1),…,x(B)∼ρx^{(1)},\ldots,x^{(B)}\sim\rhox(1),…,x(B)∼ρ，以及每个提示的 GGG 个独立回答 y(i,j)∼πθ(y∣x(i))y^{(i,j)}\sim\pi_\theta(y\mid x^{(i)})y(i,j)∼πθ​(y∣x(i))，策略梯度的样本估计为：

它提高高奖励回答的权重。下面从这个基本估计器出发，逐项修改，得到 GRPO。

4.1.5 基线

基本 REINFORCE 估计器虽然期望正确，等于 ∇θJθ\nabla_\theta J_\theta∇θ​Jθ​，但方差较大，使训练不稳定。基线是降低方差、稳定训练的一种工具。

基线可以很复杂，最简单的做法是从奖励中减去常数 bbb：

Ex∼ρEy∼πθ(y∣x)[(r(y∣x)−b)∇θlog⁡πθ(y∣x)].(15)\mathbb E_{x\sim\rho}\mathbb E_{y\sim\pi_\theta(y\mid x)}[(r(y\mid x)-b)\nabla_\theta\log\pi_\theta(y\mid x)]. \tag{15}Ex∼ρ​Ey∼πθ​(y∣x)​[(r(y∣x)−b)∇θ​logπθ​(y∣x)].(15)

例如奖励为二元值时，取 b=0.5b=0.5b=0.5，就以 0.5 的权重提高正确回答的概率，以 −0.5 的权重降低错误回答的概率。原始估计器则以 1 的权重强化正确回答，对错误回答不做处理，因为其权重为 0。

本节关键结论是：只要 bbb 不依赖动作／回答 yyy，减去它就保持估计器的期望不变。它可以是常数、xxx 的函数或策略的函数。即：

Ex∼ρEy∼πθ(y∣x)[(r(y∣x)−b)∇θlog⁡πθ(y∣x)]=Ex∼ρEy∼πθ(y∣x)[r(y∣x)∇θlog⁡πθ(y∣x)].(16)\mathbb E_{x\sim\rho}\mathbb E_{y\sim\pi_\theta(y\mid x)}[(r(y\mid x)-b)\nabla_\theta\log\pi_\theta(y\mid x)] =\mathbb E_{x\sim\rho}\mathbb E_{y\sim\pi_\theta(y\mid x)}[r(y\mid x)\nabla_\theta\log\pi_\theta(y\mid x)]. \tag{16}Ex∼ρ​Ey∼πθ​(y∣x)​[(r(y∣x)−b)∇θ​logπθ​(y∣x)]=Ex∼ρ​Ey∼πθ​(y∣x)​[r(y∣x)∇θ​logπθ​(y∣x)].(16)

这直接来自恒等式：

Ey∼πθ(y∣x)[∇θlog⁡πθ(y∣x)]=∇θEy∼πθ(y∣x)[1]=0.(17)\mathbb E_{y\sim\pi_\theta(y\mid x)}[\nabla_\theta\log\pi_\theta(y\mid x)] =\nabla_\theta\mathbb E_{y\sim\pi_\theta(y\mid x)}[1]=0. \tag{17}Ey∼πθ​(y∣x)​[∇θ​logπθ​(y∣x)]=∇θ​Ey∼πθ​(y∣x)​[1]=0.(17)

第一步逆向使用了对数导数技巧。

基线保持期望，却可能增大或减小方差。若将估计器写为样本均值 1n∑i=1nZi\frac1n\sum_{i=1}^n Z_in1​∑i=1n​Zi​，每个 ZiZ_iZi​ 是一个样本 (x,y)(x,y)(x,y) 对应的 (r(y∣x)−b)∇θlog⁡πθ(y∣x)(r(y\mid x)-b)\nabla_\theta\log\pi_\theta(y\mid x)(r(y∣x)−b)∇θ​logπθ​(y∣x)，则估计器方差为 [E(Zi2)−E(Zi)2]/n[\mathbb E(Z_i^2)-\mathbb E(Z_i)^2]/n[E(Zi2​)−E(Zi​)2]/n。下一题探索何时基线增大或减小方差。

经过组均值调整的奖励通常称为“优势”：它不再表示绝对奖励，而表示当前 rollout 相对平均奖励的优势。

4.1.6 优势归一化

减去组均值之后，GRPO 的下一项修改是除以组标准差：

g^←1BG∑i=1B∑j=1Gr(y(i,j)∣x(i))−μistdi∇θlog⁡πθ(y(i,j)∣x(i)).(25)\hat g\leftarrow\frac1{BG}\sum_{i=1}^B\sum_{j=1}^G \frac{r(y^{(i,j)}\mid x^{(i)})-\mu_i}{\mathrm{std}_i} \nabla_\theta\log\pi_\theta(y^{(i,j)}\mid x^{(i)}). \tag{25}g^​←BG1​i=1∑B​j=1∑G​stdi​r(y(i,j)∣x(i))−μi​​∇θ​logπθ​(y(i,j)∣x(i)).(25)

其中 stdi=1G∑j=1G(r(y(i,j)∣x(i))−μi)2\mathrm{std}_i=\sqrt{\frac1G\sum_{j=1}^G(r(y^{(i,j)}\mid x^{(i)})-\mu_i)^2}stdi​=G1​∑j=1G​(r(y(i,j)∣x(i))−μi​)2​。注意，默认 torch.std 使用略有不同的样本标准差表达式进行偏差校正；实现时应使用默认 torch.std。

除以标准差不再保持估计器期望，因此我们不再对原始期望奖励目标 JθJ_\thetaJθ​ 做梯度上升。可以把它理解为稳定性技巧：假设各梯度向量独立同分布且服从高斯分布，那么除以组标准差会使各组更新的范数大致相同。下一节将进一步研究优势归一化。

4.1.7 序列归一化

GRPO 还有一个似乎继承自早期 LLM-PPO 实现的细节，称为序列归一化。把回答的对数概率展开为时间步之和，当前估计器为：

g^←1BG∑i=1B∑j=1Gr(y(i,j)∣x(i))−μistdi∇θ∑t=1len⁡(y(i,j))log⁡πθ(yt(i,j)∣x(i),y<t(i,j)).(26)\hat g\leftarrow\frac1{BG}\sum_{i=1}^B\sum_{j=1}^G \frac{r(y^{(i,j)}\mid x^{(i)})-\mu_i}{\mathrm{std}_i} \nabla_\theta\sum_{t=1}^{\operatorname{len}(y^{(i,j)})} \log\pi_\theta(y_t^{(i,j)}\mid x^{(i)},y_{<t}^{(i,j)}). \tag{26}g^​←BG1​i=1∑B​j=1∑G​stdi​r(y(i,j)∣x(i))−μi​​∇θ​t=1∑len(y(i,j))​logπθ​(yt(i,j)​∣x(i),y<t(i,j)​).(26)

GRPO 加入额外的序列长度归一化项：

g^←1BG∑i=1B∑j=1Gr(y(i,j)∣x(i))−μistdi∇θ(1len⁡(y(i,j))∑t=1len⁡(y(i,j))log⁡πθ(yt(i,j)∣x(i),y<t(i,j))).(27)\hat g\leftarrow\frac1{BG}\sum_{i=1}^B\sum_{j=1}^G \frac{r(y^{(i,j)}\mid x^{(i)})-\mu_i}{\mathrm{std}_i} \nabla_\theta\left(\frac1{\operatorname{len}(y^{(i,j)})} \sum_{t=1}^{\operatorname{len}(y^{(i,j)})}\log\pi_\theta(y_t^{(i,j)}\mid x^{(i)},y_{<t}^{(i,j)})\right). \tag{27}g^​←BG1​i=1∑B​j=1∑G​stdi​r(y(i,j)∣x(i))−μi​​∇θ​​len(y(i,j))1​t=1∑len(y(i,j))​logπθ​(yt(i,j)​∣x(i),y<t(i,j)​)​.(27)

这进一步改变了期望：不同序列的 token 不再具有相同权重，长序列 token 相对短序列 token 的权重更低。下一节会讨论并通过消融实验判断这种修改是否合适。目前先按原始论文实现标准 GRPO，因此保留序列归一化。

4.1.8 将所有部分组合起来

尚未介绍的 GRPO 组件是带裁剪的重要性加权，后面讨论异策略 RL 时会讲解。简而言之，同策略 RL 对每个推理批次做一次梯度更新，异策略 RL 则做多次更新以提高速度。“异策略”指第二次及之后更新使用的样本已经过时，因为它们来自较旧版本的模型。重要性加权修改梯度估计器，使其能够使用旧样本。现在只做同策略 RL，暂时不需要它。
