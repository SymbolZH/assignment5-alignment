服务与 SSH 命令（首次配置，后续复用）

在远程服务器执行以下命令，后台启动服务；已有服务时无需重复启动：

nohup python -m http.server 8765 \
  --bind 127.0.0.1 \
  --directory /home/zhanghao/my_code/assignment5-alignment/html_learn \
  > /tmp/html-learn-http.log 2>&1 < /dev/null &

本地连接服务器时，加上端口转发；这同一条连接也提供交互终端：

ssh -L 8765:127.0.0.1:8765 你的服务器别名或用户名@地址

本地浏览器打开 http://127.0.0.1:8765/assignment5-requirements.html。修改后刷新即可。需要单独建立隧道时，可使用：

ssh -N -L 8765:127.0.0.1:8765 你的服务器别名或用户名@地址

服务只绑定服务器的 127.0.0.1:8765。SSH 断线后需恢复端口转发，服务器重启后需重新启动 HTTP 服务。
